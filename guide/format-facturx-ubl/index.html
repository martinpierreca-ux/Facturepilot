Factur-X et UBL : les formats de facture électronique

La réforme impose des factures dans des formats structurés lisibles par les machines. Factur-X, UBL, CII — voici ce que chaque format signifie et lequel privilégier pour votre activité.

Au sommaire
  1. Pourquoi des formats structurés ?
  2. Factur-X : le format hybride PDF + XML
  3. UBL et CII
  4. Quel format choisir ?

Pourquoi des formats structurés ?

Une facture électronique au sens de la réforme n'est pas un simple PDF. Elle doit contenir des données structurées (XML) que les systèmes informatiques peuvent lire et traiter automatiquement. Cela permet la vérification automatique par l'administration fiscale et l'intégration comptable.

Factur-X : le format hybride PDF + données XML

Factur-X est le format recommandé en France. C'est un PDF/A-3 qui embarque un fichier XML dans ses métadonnées. Avantages :

  • Le PDF reste lisible par l'œil humain comme avant
  • Les données XML permettent le traitement automatique
  • Compatible avec les outils existants
  • Norme franco-allemande (ZUGFeRD en Allemagne)

Factur-X existe en plusieurs profils selon la complexité (Minimum, Basic, EN16931…). Pour les auto-entrepreneurs, le profil Minimum ou Basic suffit.

UBL et CII

UBL (Universal Business Language) et CII (Cross Industry Invoice) sont des formats XML purs, sans PDF lisible. Ils sont davantage utilisés dans les relations B2B avec des grandes entreprises ou pour les marchés publics (Chorus Pro).

Quel format choisir en pratique ?

Pour les auto-entrepreneurs : laissez votre PDP choisir pour vous. Les plateformes comme Indy, Pennylane ou le PPF gèrent la conversion au bon format automatiquement. Vous n'avez pas besoin de comprendre le XML.

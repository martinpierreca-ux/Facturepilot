Numérotation des factures auto-entrepreneur : les règles à respecter

La numérotation des factures est une mention obligatoire. Un trou dans la séquence peut alerter l'administration fiscale lors d'un contrôle. Voici ce que dit la loi et les bonnes pratiques.

Au sommaire
  1. Les règles légales
  2. Quel format choisir ?
  3. Que faire en cas de trou ?

Les règles légales de numérotation

L'article 242 nonies A de l'annexe II du CGI impose que les factures soient numérotées selon une séquence chronologique et continue sans rupture. Concrètement :

  • Chaque facture doit avoir un numéro unique
  • Les numéros doivent se suivre sans interruption
  • La numérotation doit être croissante dans le temps
  • Vous ne pouvez pas réutiliser un numéro, même si la facture a été annulée
Attention : Un trou de numérotation (ex. F-001 puis F-003) peut être interprété par le fisc comme une tentative de dissimulation de revenus.

Quel format de numérotation choisir ?

La loi ne prescrit pas de format spécifique, mais les pratiques courantes incluent :

  • F-2026-001, F-2026-002… — Préfixe + année + numéro incrémental
  • 2026-001, 2026-002… — Sans préfixe
  • F001, F002… — Simple, mais réinitialiser chaque année peut créer des doublons si vous facturez depuis plusieurs années

La formule préfixe + année + numéro est recommandée : elle facilite le classement et évite les doublons entre exercices.

Que faire en cas de trou de numérotation ?

Si vous réalisez avoir sauté un numéro :

  1. Ne modifiez pas les factures existantes — c'est illégal
  2. Conservez une trace écrite expliquant le trou (erreur de saisie, facture annulée…)
  3. Si une facture a été annulée, émettez un avoir avec ce numéro
  4. Continuez la séquence normalement

Séries séparées par type de document

Il est possible (et recommandé) d'avoir des séquences distinctes pour chaque type de document :

  • F-2026-XXX → factures
  • D-2026-XXX → devis
  • AV-2026-XXX → avoirs
  • FA-2026-XXX → factures d'acompte

Chaque série doit être continue en elle-même. FacturePilot gère automatiquement cette numérotation.

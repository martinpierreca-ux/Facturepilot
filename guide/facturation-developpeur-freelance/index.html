Facturation pour développeur freelance

Statut, TJM, mentions obligatoires et propriété intellectuelle : tout ce que le développeur freelance doit savoir pour facturer correctement.

Quel statut pour un développeur freelance ?

La plupart des développeurs freelance en France choisissent entre :

  • Auto-entrepreneur (micro-BIC) : idéal pour démarrer ou pour un CA < 60 000 €. Simple, cotisations proportionnelles au CA.
  • SASU ou EURL : recommandé au-delà de 60 000 € de CA ou si vous voulez optimiser votre rémunération via dividendes.
  • Portage salarial : si vous préférez rester salarié sans gérer une structure.

TJM moyen d'un développeur freelance en 2026

Les TJM varient fortement selon le niveau et la techno :

Profil TJM moyen
Junior (1–3 ans)250–400 €/j
Confirmé (3–7 ans)450–650 €/j
Senior (7 ans+)650–900 €/j
Architecte / Lead800–1 200 €/j

Mentions obligatoires sur vos factures

En tant que développeur freelance en auto-entrepreneur, vos factures doivent inclure toutes les mentions standard. Côté activité : vous êtes généralement en micro-BIC prestation de services, donc la mention « TVA non applicable – art. 293 B CGI » est obligatoire si sous le seuil.

Propriété intellectuelle : une attention particulière

En tant que développeur, la question des droits sur le code livré est centrale :

  • Par défaut : vous restez propriétaire du code jusqu'au paiement intégral
  • Précisez dans le contrat : s'il y a cession de droits, à quelle condition et dans quel cadre
  • Code open source vs propriétaire : mentionnez les licences utilisées
  • Le client peut réutiliser le code livré mais pas forcément les outils ou frameworks propriétaires que vous utilisez

Comment facturer une régie vs au forfait ?

  • Régie (TJM) : vous facturez à la journée. Simple, mais nécessite de tracker précisément vos jours travaillés.
  • Forfait : prix fixe pour un périmètre défini. Vous portez le risque de dépassement — compensé par une marge plus élevée.

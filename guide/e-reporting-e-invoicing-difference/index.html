E-invoicing vs e-reporting : quelle différence ?

La réforme de la facturation électronique se divise en deux obligations distinctes. Comprendre laquelle vous concerne est essentiel pour anticiper sans stress.

Au sommaire
  1. L'e-invoicing : facturation entre assujettis français
  2. L'e-reporting : les autres transactions
  3. Ce qui change pour les auto-entrepreneurs
  4. Le calendrier

L'e-invoicing : facturation électronique structurée

L'e-invoicing concerne les transactions B2B entre entreprises françaises assujetties à la TVA. Il impose :

  • L'émission de factures dans un format structuré (Factur-X, UBL…) via une PDP ou le PPF
  • La réception des factures via ce même canal

C'est le remplacement de l'envoi de factures PDF par email entre professionnels français.

L'e-reporting : communication des données

L'e-reporting concerne les transactions non couvertes par l'e-invoicing :

  • Ventes B2C (particuliers)
  • Ventes à des entreprises étrangères
  • Transactions avec des non-assujettis

Pour ces opérations, vous devez transmettre les données de transaction à l'administration fiscale via le PPF ou une PDP. Pas de facture structurée, mais une synthèse de vos ventes.

Ce qui change pour les auto-entrepreneurs

E-invoicing : Si vous facturez des entreprises françaises assujetties à la TVA, vous devrez émettre vos factures en format structuré via une PDP.
E-reporting : Si vous vendez à des particuliers ou à l'étranger, vous devrez transmettre périodiquement un résumé de vos transactions.

Dans les deux cas, des solutions gratuites ou à bas coût existent (PPF, offres PDP pour les petits volumes).

Le calendrier d'entrée en vigueur

  • 1er septembre 2026 : obligation pour les grandes entreprises
  • 1er septembre 2027 : obligation pour les ETI
  • 1er septembre 2027 : obligation pour les PME et micro-entreprises

En attendant, préparez-vous en choisissant votre PDP et en adaptant votre logiciel de facturation.
